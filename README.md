# CGV + 메가박스 예매 오픈 알리미 (개인용)

[cgv-open-push](https://github.com/0w0i0n0g0/cgv-open-push)와 [megabox-open-push](https://github.com/0w0i0n0g0/megabox-open-push)를 하나로 합치고,
**원하는 영화관을 직접 검색해서 추가**할 수 있게 만든 버전입니다. 오라클 무료 서버에서 24시간 돌리며 **1분마다** 확인하고, 새 예매 날짜가 열리면 **디스코드**로 알립니다.

## 파일
| 파일 | 역할 |
|---|---|
| `manage.py` | 영화관 추가·삭제, 디스코드 설정, 서버 설치 스크립트 만들기 (메뉴) |
| `main.py` | 알리미 본체 (서버에서 자동 실행됨. PC에서 `python main.py`로 직접 돌려볼 수도 있음) |
| `cgv.py` / `megabox.py` | 각 사이트 조회 |
| `server_script.py` | 오라클 설치 스크립트(`oracle_setup.sh`) 생성 |
| `common.py` | 설정·로그·인터넷 요청·디스코드 전송 |

추가 설치 필요 없음 (파이썬 3 기본 기능만 사용).

## 빈자리 감시 (manage.py 9번 메뉴)
극장·영화·회차 키워드(예: `아트그라피`)·날짜·시간 조건에 맞는 회차에서 **예매 가능한 일반석**이 비면 알립니다.
- 1단계: 1분마다 회차 목록의 잔여석 숫자만 확인 (가벼운 요청)
- 2단계: 숫자가 바뀐 회차만 좌석 배치도를 열어 일반석 빈자리만 셈 (처음 시작할 때도 한 번 확인)
- 같은 좌석은 한 번만 알리고, 팔린 뒤 다시 비면 다시 알림
- 좌석 배치도 요청은 사이트별 최소 간격(CGV 4초, 메가박스 2초), 1분에 최대 6회. 실패가 이어지면 최대 10분까지 천천히 재시도
- 로그인·자동 예매·결제는 하지 않습니다

'일반석'으로 볼 값은 `config.json`의 `seat_filter`에서 고칠 수 있습니다 (2026-11 실제 응답 기준 기본값):
- CGV: 좌석 종류 `일반석`·`SWEETBOX`, 판매 형태 `일반` (빼는 것: `PRIVATE 2인`, 장애인석 `이동식`, `판매중지`)
- 메가박스: 좌석 등급 `GERN_CLS`·`2P_CLS`(2인소파석), 구역 `GERN_ZONE` (빼는 것: 장애인석 `DISABLED_CLS`)
일반석이 아니라서 제외된 빈 좌석 종류는 로그에 한 번씩 남습니다.

## 디스코드로 오는 메시지
- 🎬 **예매 오픈 알림**: 새 회차가 열렸을 때
- 💺 **빈자리 알림**: 감시 중인 회차에 일반석이 비었을 때 (좌석 번호, 예매 링크 포함)
- ✅ 시작 알림: 서버가 켜지거나 재시작됐을 때
- 🟢 매일 오전 9시 정상 작동 보고 → **이 메시지가 안 오면 서버가 멈춘 것**
- ⚠️ 조회가 10번 연속 실패했을 때 (사이트 구조 변경, 접속 차단 등)

## 설정값 (`config.json`)
- `interval_seconds`: 확인 간격(초). 기본 60. 30 미만은 허용 안 함 (차단 위험)
- `daily_report_hour`: 매일 보고 시각. 기본 9

## 영화관을 바꾸고 싶을 때
`python manage.py`에서 추가/삭제 → 7번으로 스크립트 다시 만들기 → 오라클에서 기존 서버 삭제(종료) 후 새로 만들기.

## 원본과 달라진 점
- CGV: 리뉴얼 전 주소(ticket.cgv.co.kr) → 현재 사이트 API(`cgv.co.kr/api/v1/booking/...`)
- 알림: 디스코드 봇 → 웹후크, 조회 간격 5분 → 1분, 상태/오류 알림 추가
- Flask 상태 페이지·Docker 제외, 오류 시 해당 영화관만 재시도

## 라이선스
원본과 같은 **AGPL-3.0**. 개인 사용은 자유, 수정본을 배포하거나 공개 서비스로 운영하면 소스 공개 의무가 있습니다.
CGV·메가박스와 무관한 비공식 도구이며, 사이트 구조가 바뀌면 동작하지 않을 수 있습니다.
